# UAD 360 Panorama

SketchUp에서 360° 파노라마 JPG/PNG를 내보내는 확장의 공개 배포 저장소입니다.

## 다운로드

[최신 릴리스 및 설치 파일](https://github.com/Boilorange6/uad360/releases/latest)

Assets의 `.rbz` 파일을 다운로드하고 SketchUp **확장 관리자 → 확장 설치**에서 선택한 뒤 재시작하세요.

## 주요 기능

- 2K·4K·8K 내보내기, 360° 미리보기
- 촬영 지점 저장과 바닥 기준 카메라 높이 배치
- 촬영 화면 정리와 고정 조명 옵션
- 새 버전 자동 확인 및 설치 안내

지원 대상: **Windows SketchUp Desktop 2021~2026**. 초기 배포 버전이며 버전별 실기 검증 범위와 제한은 각 릴리스 노트에 명시합니다.

이 저장소는 설치 파일과 업데이트 정보를 배포합니다. `latest.json`은 확장의 자동 업데이트용 파일입니다.
